I am building BuckParts (buckparts.com), a truth-first homeowner-help system that helps people find the correct replacement filter for home appliances before they order the wrong part. BuckParts is not an online store. It compares model and part evidence, shows uncertainty when proof is weak, and displays buying options only after internal safety checks.
